OVERVIEW                                      *markdown-table-wrap-overview*

markdown-table-wrap.nvim renders Markdown pipe tables with wrapped cell content.
It does not modify the source Markdown buffer. The default display mode is a
full-document Reader. Source-position-preserving inline replacement and a
floating preview remain available as optional modes.

READER MODE

Reader mode mirrors the document into a read-only scratch buffer and replaces
every pipe table with real Unicode buffer lines. It never modifies the source
Markdown buffer. With auto_preview enabled, Reader opens automatically for
Markdown buffers and renders every table without requiring cursor focus.

Unlike inline extmark replacement, reader mode is not layered over long raw
table rows. Native wrap therefore cannot reveal source pipes or URLs beneath
the rendered table.

Default interaction:

- Normal mode stays in Reader.
- v/V/CTRL-V select real rendered lines. Yank keeps Reader active.
- i/a/I/A/o/O switch to the corresponding source line for editing. Reader
  reopens after InsertLeave.
- |:MarkdownTableToggleReader| switches between Reader and Source.
- |:MarkdownTableEditSource| leaves Reader and pauses automatic reopening.
- gx opens the original URL under a rendered link.

To copy original Markdown syntax rather than the rendered table, toggle to
Source first and use Visual mode there.

When optional inline mode is selected, complete-table rendering remains the
default and viewport slicing remains disabled.

If you enable |inline_viewport_scrolling|, the plugin instead keeps inline
rendering inside the original source table height and lets you move through the
rendered slice with |:MarkdownTableScrollDown|, |:MarkdownTableScrollUp|,
|:MarkdownTableScrollTop|, and |:MarkdownTableScrollBottom|.

The plugin is designed to coexist with render-markdown.nvim by letting
render-markdown.nvim handle non-table Markdown while markdown-table-wrap.nvim
owns pipe table rendering.

Requirements:

- Neovim 0.10+
- No external binary dependencies

==============================================================================
INSTALLATION                                  *markdown-table-wrap-installation*

Example lazy.nvim / LazyVim spec:
>
  return {
    {
      "your-name/markdown-table-wrap.nvim",
      ft = "markdown",
      opts = {},
    },
  }
<

For local development:
>
  return {
    {
      dir = "~/Code/lazyvim-table/markdown-table-wrap.nvim",
      ft = "markdown",
      opts = {},
    },
  }
<

Example LazyVim key bindings:
>
  keys = {
    {
      "<leader>mr",
      "<cmd>MarkdownTableToggleReader<cr>",
      desc = "Toggle Markdown reader/source",
    },
    {
      "<leader>me",
      "<cmd>MarkdownTableEditSource<cr>",
      desc = "Edit Markdown source",
    },
  }
<

These commands change the current view; they do not modify preview_mode.
ToggleReader is bidirectional. EditSource is one-way and pauses automatic
reopening until Reader is explicitly opened again.

==============================================================================
COMMANDS                                      *markdown-table-wrap-commands*

                                                        *:MarkdownTablePreview*
:MarkdownTablePreview
    Open the configured preview mode. Defaults to Reader.

                                                  *:MarkdownTableInlinePreview*
:MarkdownTableInlinePreview
    Render the table under the cursor inline.

                                                   *:MarkdownTableFloatPreview*
:MarkdownTableFloatPreview
    Render the table under the cursor in a floating window.

                                                   *:MarkdownTableReader*
:MarkdownTableReader
    Open the full Markdown document in the rendered reader.

                                             *:MarkdownTableToggleReader*
:MarkdownTableToggleReader
    Switch the current window between Reader and Source. Leaving Reader pauses
    automatic reopening until this command is run again.

                                               *:MarkdownTableEditSource*
:MarkdownTableEditSource
    Leave Reader, pause automatic reopening, and keep Source visible.

                                                  *:MarkdownTableTogglePreview*
:MarkdownTableTogglePreview
    Toggle the active preview.

                                                   *:MarkdownTableClosePreview*
:MarkdownTableClosePreview
    Close the preview and clear inline rendering.

                                                        *:MarkdownTableRefresh*
:MarkdownTableRefresh
    Force refresh Markdown table rendering in the current buffer.

                                             *:MarkdownTableEnableAutoPreview*
:MarkdownTableEnableAutoPreview
    Enable automatic table rendering in the current buffer.

                                            *:MarkdownTableDisableAutoPreview*
:MarkdownTableDisableAutoPreview
    Disable automatic table rendering in the current buffer.

                                             *:MarkdownTableToggleAutoPreview*
:MarkdownTableToggleAutoPreview
    Toggle automatic table rendering in the current buffer.

                                                       *:MarkdownTableStatus*
:MarkdownTableStatus
    Show the current rendering state.

                                           *:MarkdownTableToggleInlineViewport*
:MarkdownTableToggleInlineViewport
    Toggle between viewport-sliced inline rendering and full inline rendering.

                                                       *:MarkdownTableNextCell*
:MarkdownTableNextCell
    Move to the next source table cell.

                                                       *:MarkdownTablePrevCell*
:MarkdownTablePrevCell
    Move to the previous source table cell.

                                                        *:MarkdownTableNextRow*
:MarkdownTableNextRow
    Move to the same source table cell in the next row.

                                                       *:MarkdownTablePrevRow*
:MarkdownTablePrevRow
    Move to the same source table cell in the previous row.

                                                      *:MarkdownTableOpenLink*
:MarkdownTableOpenLink
    Open the first link in the current source table cell.

                                                     *:MarkdownTableScrollDown*
:MarkdownTableScrollDown
    Scroll the rendered table view down.

                                                       *:MarkdownTableScrollUp*
:MarkdownTableScrollUp
    Scroll the rendered table view up.

                                                      *:MarkdownTableScrollTop*
:MarkdownTableScrollTop
    Jump the rendered table viewport to the top.

                                                   *:MarkdownTableScrollBottom*
:MarkdownTableScrollBottom
    Jump the rendered table viewport to the bottom.

CONFIGURATION                              *markdown-table-wrap-configuration*

Default setup:
>
  require("markdown-table-wrap").setup({
    max_width_ratio = 0.9,
    min_col_width = 8,
    max_col_width = 50,
    fit_to_window = true,
    border = "rounded",
    use_unicode_border = true,
    table_border = "rounded",
    row_separator = true,
    preview_mode = "reader",
    inline_mode = "replace",
    inline_position = "above",
    dim_source = true,
    auto_preview = true,
    render_all = true,
    auto_preview_in_insert = false,
    clear_on_cursor_leave = true,
    clear_on_insert = true,
    clear_on_visual = true,
    debounce_ms = 80,
    overlay_priority = 10000,
    overlay_fill = true,
    inline_virtual_text = "overlay",
    inline_disable_wrap = true,
    inline_wrap_scope = "cursor",
    inline_viewport_scrolling = false,
    reader = {
      wrap = true,
      linebreak = false,
      breakindent = true,
      conceallevel = 2,
      concealcursor = "nvc",
    },
    highlight_preset = "default",
    theme_dir = nil,
    themes = {},
    highlights = {},
    link = {
      wiki = { icon = " ", highlight = "MarkdownTableWrapWikiLink", scope_highlight = "MarkdownTableWrapWikiLink" },
      image = " ",
      custom = {
        github = { pattern = "github", icon = " " },
        gitlab = { pattern = "gitlab", icon = "󰮠 " },
        youtube = { pattern = "youtube", icon = " " },
        bilibili = { pattern = "bilibili", icon = "󰟴 " },
        cern = { pattern = "cern.ch", icon = " " },
      },
    },
    map_gx = true,
  })
<

Important options:

max_width_ratio~
    Maximum rendered table width as a ratio of the current window width.

min_col_width~
    Minimum display width for a column.

max_col_width~
    Maximum natural display width before wrapping.

fit_to_window~
    Prioritize keeping the complete table inside the current window text area.
    When necessary, columns may become narrower than min_col_width.

preview_mode~
    "reader" (default), "inline", or "float".

reader~
    Window options for the full-document reader. By default ordinary Markdown
    uses wrap and breakindent, while linebreak remains disabled. Table rows are
    already wrapped by the plugin and stay inside the computed text width.

inline_mode~
    "replace" hides source text and overlays rendered rows.
    "insert" shows rendered rows above or below the source table.

inline_virtual_text~
    "overlay" or "win_col" for the replace-mode virtual text strategy.
    "overlay" is the default and is generally the most portable choice.

inline_disable_wrap~
    Enables the temporary nowrap protection for inline replace mode. Long
    concealed source rows can otherwise soft-wrap underneath the rendered
    table on some terminal and platform combinations.

inline_wrap_scope~
    Controls where |inline_disable_wrap| applies:

    "always" disables wrap for the whole window while inline tables are
       active. This is the strictest and most stable setting.

    "cursor" (the default) disables wrap only while the cursor is inside a
    rendered table, then restores the previous window-local wrap setting so
    ordinary Markdown paragraphs continue to wrap normally.

    "never" leaves wrap fully under user control. This may allow concealed
    source rows to leak or flicker on long tables.

clear_on_visual~
    In inline mode, reveal source Markdown while selecting text and re-render
    after leaving Visual mode. Reader mode selects real rendered lines and
    stays active after yank.

auto_preview~
    Automatically open Reader for Markdown buffers, or refresh the selected
    non-Reader preview strategy.

render_all~
    Render all tables in the current Markdown buffer.

highlight_preset~
    "default", "tokyonight", "catppuccin", "render_markdown", or "auto".
    The default preset links to standard Neovim highlight groups so it works
    naturally with arbitrary colorschemes.

theme_dir~
    Optional directory containing custom theme files named <preset>.lua.

themes~
    Inline custom theme table keyed by preset name.

inline_viewport_scrolling~
    When enabled, |:MarkdownTableScrollDown| and |:MarkdownTableScrollUp|
    page through rendered rows inside the original table height.

    When disabled, the complete rendered table is shown inline with extra
    virtual lines. This is the default because it is less surprising on first
    use. In that mode, scroll commands fall back to normal window scrolling
    because the table is already expanded visually.

link~
    Icon configuration for links, wiki links, images, and URL pattern matches.
    Standard Markdown links use [text](url). The plugin also accepts
    (text)[url] as a convenience form inside table cells.

map_gx~
    Map gx in Markdown buffers to |:MarkdownTableOpenLink| with fallback to
    native gx. This avoids opening the concealed source word under rendered
    virtual text, such as trying to open "Details" instead of the source URL.

extra_filetypes~
    List of additional filetypes to enable table rendering for. The default
    is {}, meaning only markdown, md, quarto, and rmarkdown buffers
    render tables. Example:
>
      require("markdown-table-wrap").setup({
        extra_filetypes = { "text" },
      })
<
    NOTE for LazyVim users: If you add extra filetypes, you must also
    include them in the plugin's ft list to load the plugin for those
    filetypes:
>
      return {
        {
          "ice345/markdown-table-wrap.nvim",
          ft = { "markdown", "text" },
          opts = {
            extra_filetypes = { "text" },
          },
        },
      }
<

RENDER-MARKDOWN.NVIM                    *markdown-table-wrap-render-markdown*

To avoid double table rendering, disable render-markdown.nvim pipe tables:
>
  return {
    "MeanderingProgrammer/render-markdown.nvim",
    opts = {
      pipe_table = {
        enabled = false,
      },
    },
  }
<

==============================================================================
LIMITATIONS                                *markdown-table-wrap-limitations*

- Inline replacement uses virtual text and optional virtual lines. These are
  visual rows, not real buffer rows. Use |:MarkdownTableScrollDown| /
  |:MarkdownTableScrollUp| to page through the inline rendered slice, or use
  |:MarkdownTableReader| / |:MarkdownTableFloatPreview| for a normal
  scrollable preview buffer.
- Terminal and platform combinations can differ in how wrap, conceal, and
  virtual text interact. The default |inline_disable_wrap| setting exists to
  prevent concealed long source rows from leaking through below the rendered
  table on some terminal setups. Reader mode avoids this extmark/wrap
  interaction entirely.
- Treesitter-aware table discovery is not implemented yet.
- The plugin focuses on Markdown pipe tables and does not replace general
  Markdown rendering.
